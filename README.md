## ✨ ¿Qué es Aerio?

Aerio es una app de mantenimiento para Mac pensada para quienes quieren cuidar el rendimiento de su equipo sin arriesgar sus archivos ni perder tiempo entendiendo terminales o configuraciones complicadas. Todo se controla desde un panel simple y visual.

## 🚀 Funciones principales

- 🧹 **Liberar RAM** — libera memoria en uso al instante
- 🗑️ **Limpieza de caché** — elimina caché acumulado que ya no sirve
- 📁 **Archivos grandes** — encuentra y elimina archivos pesados que ocupan espacio
- 🌐 **DNS** — borra la caché de DNS para mejorar la conexión
- ⚡ **Velocidad de internet** — mide tu descarga y subida en tiempo real
- 🗄️ **Desinstalador de apps** — elimina apps junto con sus archivos residuales
- 🛡️ **100% seguro** — nunca borra datos protegidos ni archivos del sistema

## 💻 Requisitos

- Mac con chip Apple Silicon (M1 o posterior)
- macOS actualizado

## 🔧 Instalación y uso local (desarrollo)

**Prerrequisitos:** Node.js

1. Instala las dependencias:
   ```
   npm install
   ```
2. Configura tu `GEMINI_API_KEY` en [.env.local](.env.local)
3. Corre la app en modo desarrollo:
   ```
   npm run dev
   ```
